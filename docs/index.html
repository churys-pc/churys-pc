App Churys PC

Garantía, historial y soporte de tu PC, en tu computadora.

Esta app es para PC con Windows. Abrí este link desde tu computadora para instalarla.
Descargar para Windows
Windows 10 y 11 · 64 bits
  1. Abrí el archivo ChurysPC-Setup.exe que se descargó.
  2. Creá tu cuenta con el mismo correo que nos diste en la compra.
  3. Listo: tu PC aparece sola, verificada por Churys PC.

Si Windows muestra «Windows protegió su PC», tocá Más información y después Ejecutar de todas formas. La app se actualiza sola cuando hay una versión nueva.
